# pragma_ecs

Part of [pragma.component-ecs](https://github.com/razedproduction/pragma.component-ecs): an Entity
Component System for game engines and frameworks built on
[pragma.core](https://github.com/razedproduction/pragma.core).

Early development (M3): entities and archetype component storage (`World`, `Entity`), queries
(`Query`), resources, and systems run as tasks of the pragma.core frame graph (`Schedule`,
`View`, `Res`, `ResMut`); commands, events and change detection come next.
